Notion 연결

Notion 계정을 연결하면 워크스페이스의 데이터베이스에 자동으로 접근할 수 있습니다.

연결 버튼을 누르면 Notion 승인 화면이 열립니다.
승인 화면에서 Snappy와 함께 사용할 페이지 또는 데이터베이스를 반드시 선택해주세요. 선택하지 않으면 다음 단계에서 목록이 표시되지 않습니다.
연결 전에 확인할 것 ▸
  1. 먼저 Notion 템플릿을 개인 워크스페이스로 복제합니다.
  2. 아래 버튼을 누르면 Notion 승인 화면으로 이동합니다.
  3. 승인 화면에서 복제한 Snappy 페이지 또는 검색 DB를 선택합니다.
  4. 허용 후 이 페이지로 돌아오면 DB 목록이 자동으로 표시됩니다.

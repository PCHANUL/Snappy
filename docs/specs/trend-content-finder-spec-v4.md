# 트렌드 콘텐츠 발견기 (Trend Content Finder)

> 키워드 하나로 매체별 인기 콘텐츠를 정리해 노션에 자동 저장하는 도구
> 작성일: 2026년 5월
> 버전: 4.0 (단순 MVP, AI 분석 제거)

---

## 1. 프로젝트 개요

### 1.1. 한 줄 소개

키워드 입력 한 번으로 매체별(네이버 블로그/유튜브/티스토리/브런치) 인기 콘텐츠를 자동으로 수집해 노션 데이터베이스에 저장하는 SaaS 도구.

### 1.2. 핵심 가치 제안

**Before**: 마케터가 매체별로 따로 검색하고, 결과를 일일이 정리하는 데 매주 5시간 소요.

**After**: 노션에서 키워드 입력 한 번 → 10초 내 매체별 인기 콘텐츠 + 직접 접속 가능한 링크가 노션에 자동 저장.

**핵심 가치 한 줄**: 키워드 입력 → 매체별 인기 콘텐츠 정리 → 링크 클릭으로 바로 접속

### 1.3. 타깃 고객

**1차 타깃**: 1인 마케터, 1인 사업자, 소상공인
- 매주 콘텐츠 트렌드 리서치 필요
- 노션을 이미 사용 중
- 도구 비용에 민감

**2차 타깃**: 콘텐츠 크리에이터
- 콘텐츠 아이디어 발굴 필요
- 경쟁 콘텐츠 참고 필요

### 1.4. 시장 포지셔닝

| 기존 솔루션 | 가격 | 한계 | 우리의 차별점 |
|---|---|---|---|
| 블랙키위 | 무료~월 5만원 | 키워드만, 콘텐츠 없음 | 실제 콘텐츠 + 링크 |
| 썸트렌드 | 월 33만원~ | 비쌈 | 1인 마케터 부담 가능 |
| 직접 검색 | 무료 | 시간 소요 | 30초 자동화 + 노션 저장 |
| 구글 트렌드 | 무료 | 매체별 분리 안 됨 | 매체별 카테고리화 |

**비어있는 자리**: 월 1만원대에 키워드 → 매체별 인기 콘텐츠를 노션에 자동 정리하는 도구.

### 1.5. 비즈니스 모델

**SaaS 월 구독 모델**

| 플랜 | 가격 | 포함 사항 |
|---|---|---|
| 베타 | 무료 | 핵심 기능 (1~2개월) |
| 라이트 | 월 9,900원 | 일 5회 검색, 7일 히스토리 |
| 스탠다드 | 월 19,900원 | 일 20회 검색, 30일 히스토리, **AI 인사이트** |
| 프리미엄 | 월 39,900원 | 무제한, AI 인사이트, 정기 모니터링 |

**중요 결정**: AI 인사이트는 스탠다드부터 제공. MVP(라이트)에는 단순 검색 + 정리만.

## 2. 핵심 기능 (MVP)

### 2.1. MVP 기능 (라이트 플랜)

**1) 노션 기반 트리거**
- 노션 DB에 키워드 입력 + 버튼 클릭
- 웹훅을 통해 서버 호출
- 결과는 노션 DB에 자동 저장

**2) 다중 매체 검색**
- 네이버 블로그 (네이버 검색 API)
- 유튜브 (YouTube Data API)
- 티스토리 (You.com)
- 브런치 (You.com)
- 매체별 5~10개 콘텐츠 추출

**3) 검색 옵션**
- 키워드 (필수)
- 매체 선택 (다중 선택)
- 기간 필터 (1일/1주/1개월/1년)
- 결과 개수 (5/10/20)

**4) 노션 자동 저장**
- 매체별 분리된 결과
- 제목 + 링크 + 간단한 설명 + 작성자/채널
- 검색 히스토리 누적

### 2.2. 스탠다드 추가 기능 (확장)

**AI 인사이트 추출** (출시 후 추가)
- 제목 패턴 분석
- 톤앤매너 분석
- 콘텐츠 갭 발견

### 2.3. 프리미엄 추가 기능 (확장)

- 콘텐츠 정기 모니터링 (주간/월간 자동 검색)
- 다중 키워드 비교
- 우선 지원

## 3. 사용자 시나리오

### 3.1. MVP 사용 시나리오

```
[김OO의 화요일 오전 9시]

1. 노션에서 "트렌드 콘텐츠 발견기" 페이지 오픈
2. 키워드 "비건 디저트" 입력
3. 매체 선택: 네이버 블로그 + 유튜브 + 티스토리
4. 기간: 1개월
5. 🚀 검색 실행 버튼 클릭
   ↓ (10초 대기)
6. 결과 확인:
   - 네이버 블로그: 10개 (제목 + 링크 + 작성자)
   - 유튜브: 10개 (제목 + 링크 + 채널)
   - 티스토리: 10개 (제목 + 링크)
7. 마음에 드는 링크 클릭 → 원문 직접 확인
8. 다음주 다시 검색 → 트렌드 변화 추적
```

**핵심**: 사용자가 직접 콘텐츠를 보고 판단해요. AI가 대신 분석하지 않아요.

## 4. 시스템 아키텍처

### 4.1. 전체 흐름

```
[사용자 노션]
    ↓ 키워드 입력 + 🚀 버튼 클릭
    ↓ 웹훅 발송

[Supabase Edge Function]
    ↓ 요청 검증
    ↓ 사용자 인증 + 사용량 체크
    ↓ 즉시 응답 반환

[병렬 매체 검색]
    ├─ 네이버 검색 API
    ├─ YouTube Data API
    ├─ You.com (티스토리)
    └─ You.com (브런치)
    ↓
    결과 통합 + 정규화

[Notion API]
    ↓ 매체별 분리해서 노션 페이지에 저장

[사용자가 노션에서 결과 확인]
```

**AI 분석 단계 제거 → 시스템 훨씬 단순**

### 4.2. 기술 스택

| 레이어 | 기술 | 비고 |

| 네이버 검색 | 네이버 검색 API | 무료 |
| 유튜브 검색 | YouTube Data API v3 | 무료 |
| 티스토리/브런치 | You.com Search API | $5/1000회 |
| 결제 (Phase 10) | 토스페이먼츠 | 한국 시장 |

**OpenAI는 MVP에서 제거.** 스탠다드 플랜 출시 시점에 추가.

## 6. API 활용 상세

### 6.1. 네이버 검색 API

**호출**:
```typescript
const response = await fetch(
  `https://openapi.naver.com/v1/search/blog.json?` +
  `query=${encodeURIComponent(keyword)}` +
  `&display=10&sort=sim`,
  {
    headers: {
      'X-Naver-Client-Id': NAVER_CLIENT_ID,
      'X-Naver-Client-Secret': NAVER_CLIENT_SECRET,
    }
  }
);
```

**응답 정규화**:
```typescript
{
  platform: 'naver_blog',
  title: stripHtml(item.title),
  url: item.link,
  description: stripHtml(item.description),
  author: item.bloggername,
  published_at: parseNaverDate(item.postdate),
}
```

### 6.2. YouTube Data API

**호출**:
```typescript
const response = await fetch(
  `https://www.googleapis.com/youtube/v3/search?` +
  `part=snippet&q=${encodeURIComponent(keyword)}` +
  `&type=video&maxResults=10&regionCode=KR` +
  `&relevanceLanguage=ko&publishedAfter=${publishedAfter}` +
  `&order=relevance&key=${YOUTUBE_API_KEY}`
);
```

### 6.3. You.com Search API

**호출 (티스토리)**:
```typescript
const response = await fetch(
  `https://ydc-index.io/v1/search?` +
  `query=${encodeURIComponent(keyword)}` +
  `&count=10&freshness=${period}` +
  `&country=KR&language=KO` +
  `&include_domains=tistory.com`,
  {
    headers: {
      'X-API-KEY': YOUCOM_API_KEY,
      'Accept': 'application/json',
    }
  }
);
```

**검증된 사실**:
- freshness 정확히 작동
- livecrawl 없이 snippets만으로 충분
- 한국어 검색 품질 우수

## 10. 차별화 포인트

### 10.1. "그냥 검색하면 되잖아?" 반박

1. **매체별 분리 결과**: 통합 검색이 아닌 카테고리화
2. **시간 누적**: 단발 검색이 아닌 트렌드 추적
3. **노션 통합**: 별도 도구 없이 워크플로우 통합
4. **자동화**: 매체별로 따로 검색할 필요 없음

### 10.2. "ChatGPT 쓰면 되잖아?" 반박

- ChatGPT는 실시간 검색 한계
- 매번 수동 프롬프트 필요
- 결과 누적 안 됨
- 매체별 분리 안 됨

### 10.3. "블랙키위 쓰면 되잖아?" 반박

- 블랙키위는 키워드 데이터
- 우리는 실제 콘텐츠 + 링크
- 직접 콘텐츠에 접속 가능
